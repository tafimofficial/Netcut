========================================================================
                      NETSTALKER - NETWORK TOOLKIT
                     (Bandwidth Limiter, Cut & Sniffer)
========================================================================

এই ফোল্ডারটি অন্য যেকোনো নতুন কম্পিউটারে (New PC) নিয়ে সফলভাবে চালানোর জন্য
নিচের সহজ নির্দেশনাবলী অনুসরণ করুন।

------------------------------------------------------------------------
১. নতুন পিসিতে চালাতে যা যা লাগবে (Prerequisites / Requirements):
------------------------------------------------------------------------

[১] Npcap ড্রাইভার (আবশ্যক / MANDATORY):
    - NetStalker নেটওয়ার্ক প্যাকেট স্নাইফ, স্পুফ এবং স্পিড নিয়ন্ত্রণ করার জন্য
      Npcap ড্রাইভার ব্যবহার করে।
    - আপনার সুবিধার জন্য এই ফোল্ডারেই `npcap-installer.exe` দিয়ে দেওয়া হয়েছে।
    - নতুন পিসিতে আগে `npcap-installer.exe` ইনস্টল করে নিন।
      (ইনস্টলের সময় "Install Npcap in WinPcap API-compatible Mode" টিক দিয়ে রাখবেন)।
    - অফিসিয়াল ডাউনলোড লিঙ্ক: https://npcap.com/#download

[২] .NET Framework 4.7.2 বা তার উপরের ভার্সন:
    - উইন্ডোজ ১০ (ভার্সন 1803 বা তার পরবর্তী) এবং উইন্ডোজ ১১-এ এটি আগে থেকেই ইনস্টল থাকে।
    - উইন্ডোজ ৭ বা ৮ হলে মাইক্রোসফটের ওয়েবসাইট থেকে .NET Framework 4.7.2 Runtime ইনস্টল করুন।

[৩] অ্যাডমিনিস্ট্রেটর পারমিশন (Run as Administrator):
    - নেটওয়ার্ক অ্যাডাপ্টার ও র' সকেট অ্যাক্সেসের জন্য উইন্ডোজে অ্যাডমিন পারমিশন বাধ্যতামূলক।

[৪] ফোল্ডারের ফাইলগুলো একসাথে রাখা:
    - `NetStalker.exe` কে কখনো একা আলাদা করবেন না।
    - এর সাথে থাকা সব `.dll` এবং `NetStalker.exe.config` ফাইল একই ফোল্ডারে থাকতে হবে।
    - জিপ (ZIP) ফাইল হলে প্রথমে "Extract All" করে আনজিপ করুন, তারপর চালান।

২. নতুন পিসিতে চালানোর নিয়ম (Step-by-Step Guide):
------------------------------------------------------------------------

ধাপ ১:
নতুন পিসিতে যদি Npcap না থাকে, তবে ফোল্ডারে থাকা `npcap-installer.exe` ডাবল-ক্লিক করে
ইনস্টল করে নিন (১ মিনিটের কাজ)।

ধাপ ২:
এই ফোল্ডারের `NetStalker.exe` ফাইলটির ওপর মাউসের Right-Click করুন।

ধাপ ৩:
"Run as administrator" নির্বাচন করুন। (UAC প্রম্পট আসলে "Yes" দিন)।

ধাপ ৪:
প্রথমে একটি অ্যাডাপ্টার সিলেকশন উইন্ডো আসবে। আপনার সক্রিয় নেটওয়ার্ক কার্ডটি
(যেমন: WiFi বা Ethernet Adapter) নির্বাচন করে "Select" চাপুন।

ধাপ ৫:
অ্যাপ ওপেন হওয়ার পর উপরে থাকা "SCAN" বাটনে ক্লিক করুন। লোকাল নেটওয়ার্কের
সবগুলো ডিভাইস (মোবাইল, ল্যাপটপ, রাউটার) স্ক্যান হয়ে লিস্টে চলে আসবে।

৩. ফিচার ব্যবহারের নিয়ম (How to Use Features):
------------------------------------------------------------------------

* ইন্টারনেট ব্লক করা (Cut / Block):
  - যেকোনো ডিভাইসের নামের পাশের "Block" চেকবক্সে টিক দিন।
  - সাথে সাথে ওই ডিভাইসের ইন্টারনেট বন্ধ হয়ে যাবে। টিক তুলে নিলে আবার ইন্টারনেট চালু হবে।

* স্পিড লিমিট করা (Download Cap & Upload Cap):
  - যেকোনো ডিভাইসের "Download Cap" বা "Upload Cap" কলামের ওপর ক্লিক করুন
    (অথবা ডিভাইসে ডাবল-ক্লিক করুন, কিংবা রাইট ক্লিক করে "Set Speed Limit" বেছে নিন)।
  - একটি স্পিড সেট করার উইন্ডো আসবে:
    - DOWNLOAD: যত KB/s স্পিডে লিমিট করতে চান তা লিখুন (যেমন: 200 বা 500 KB/s)।
    - UPLOAD: আপলোড লিমিট স্পিড লিখুন (যেমন: 100 KB/s)।
    - আনলিমিটেড করতে চাইলে 0 রাখুন।
  - "SET" বাটনে ক্লিক করুন।
  - স্বয়ংক্রিয়ভাবে রিডাইরেকশন অন হয়ে যাবে এবং ওই ডিভাইসের স্পিড ক্যাপ হয়ে যাবে!
  - কলামে সরাসরি `[Cap: 200 KB/s]` এবং লাইভ স্পিড দেখতে পাবেন।

* প্যাকেট স্নাইফার (Sniffer):
  - কোনো ডিভাইস নির্বাচন করে নিচে "SNIFFER" বাটনে চাপুন।
  - ওই ডিভাইস কোন কোন সাইট বা আইপিতে ট্রাফিক পাঠাচ্ছে তা লাইভ দেখতে পাবেন।

* নাম পরিবর্তন (Rename Device):
  - ডিভাইসে রাইট-ক্লিক করে "Set Name" দিলে ডিভাইসটি সহজেই চেনার জন্য নিজের পছন্দের নাম দিতে পারবেন।
